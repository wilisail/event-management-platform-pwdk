- Canonical asset: [temuevent-logo.svg](temuevent-logo.svg).
- The repository welcome page and both feature 2 headers use this SVG at **180 × 45 pixels**.
- Feature 2 serves an identical copy from `feature-2/public/temuevent-logo.svg`, rendered through `feature-2/components/brand.tsx`.
- Reuse the asset unchanged. Keep its colours, typography, spacing and proportions; do not redraw it as separate text/icons or add a card, tagline, outline or decoration.
- An agreed logo revision updates the canonical asset, feature 2 copy, repository image and preview screenshots together.
- The olive/azure colours in the journey diagram indicate feature ownership; they are not TemuEvent logo colours.
