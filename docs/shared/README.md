## How to use / Cara menggunakan

**ID:** Ini acuan untuk Rizky, Wili, dan coding agent masing-masing. Urutan pertimbangan: PRD terbaru → materi kursus → prototype F1 yang diterima → pola UX dari referensi resmi → pilihan proyek. Materi kursus membantu implementasi; referensi website membantu memahami UX. Keduanya tidak menambah kewajiban di luar PRD.

**EN:** This reference is for Rizky, Wili and their coding agents. Consider the latest PRD first, then course guidance, the accepted F1 prototype, official UX references and project choices. Course material guides implementation; reference websites illustrate UX. Neither adds requirements beyond the PRD.

**ID:** Arah visual F1 sudah diterima oleh Wili melalui [PR #1](https://github.com/wilisail/event-management-platform-pwdk/pull/1). Rekomendasi vote belum menjadi keputusan. Belum ada suara Rizky atau Wili yang dicatat; isi hasil hanya setelah hasilnya dibagikan secara eksplisit. Perubahan keputusan dicatat dengan tanggal, alasan dan dampaknya pada kedua fitur. Perbarui versi Indonesia dan English bersamaan.

**EN:** Wili accepted F1's visual direction through [PR #1](https://github.com/wilisail/event-management-platform-pwdk/pull/1). Recommendations are pending proposals. Neither person's votes have been recorded; enter results only after they are explicitly supplied. Record decision changes with the date, reason and effects on both features. Update the Indonesian and English versions together.

**EN:** `main/docs/shared` is the reference link. The notes are also carried into `integration` for combined testing.
